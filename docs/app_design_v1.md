# App 设计定稿 v1（MVP 流程 + 数据模型 + 校准方案）

更新日期：2026-08-06

## 一、MVP 用户流程（定稿）

```
首次启动 onboarding（生辰八字→命卦，可跳过/设置页可改，仅存本地+加密）
  → 新建"宅"（询问宅向/坐向，存为该宅属性）
  → 指南针校准页（用户水平持机指向北方 → 点击"开始"，记录磁航向角 θ₀）
  → ARCore 环绕扫描（起点不限，任意方向）
  → 3D 视图：物体识别标注 + 北箭头人工微调（兜底室内磁干扰）
  → 信息确认（已复用生辰+宅向，不再询问）
  → 风水报告（命卦 + 吉凶方位 + 命中规则 + 原文依据）
```

**关键交互规则**
- 生辰八字：全局用户档案，跨宅复用；支持跳过；修改后重算命卦
- 宅向（坐向）：归属"宅"实体，同宅多房间复用；新建另一宅时重新询问
- 北向：扫描前记录基准磁航向角 θ₀，扫描后自动旋转对齐磁北（罗盘惯例，非真北，无需磁偏角修正）；3D 视图保留人工拖拽校准

## 二、数据模型

```
UserProfile {
  birthInfo: 公历生日(年/月/日) + 时辰     // 敏感，加密存储
  mingua: 命卦（坎离震巽=东四命 / 乾坤艮兑=西四命）
}
House {
  id, name
  facing: 宅向/坐向        // 用于定宅卦
}
Room {
  id, houseId
  northRotation: 磁北旋转角（θ₀ + 人工微调）
  modelRef: 3D 模型引用（点云/户型多边形）
  objects: [ { type, 3D坐标, 包围框, 卦位格 } ]
}
```

## 三、北方校准技术方案

- ARCore 坐标系初始朝向随机（VIO 仅保证重力垂直）→ 必须以扫描开始时的磁航向为基准
- 校准页：旋转矢量传感器实时显示磁航向；用户指向北点"开始"→ 记录 θ₀
- 扫描后：模型整体绕垂直轴旋转，使扫描起点方向对齐磁北
- 风水方位以磁北为基准（罗盘磁针），与 app 磁力计一致，无需磁偏角修正
- 最终人工微调：3D 视图拖拽"北"箭头

## 四、规则引擎输入（与 K2 依赖矩阵一致）

- 房间事实：多边形/面积/物体位置/朝向/卦位格（ARCore 建模 + YOLO 识别 + 方向标注）
- 用户事实：命卦（生辰）、宅卦（宅向）
- 输出：命中规则 → 吉/凶分组 → 每条含白话结论/化解建议/原文依据（可折叠）

## 五、隐私口径

- 全离线端上计算；生辰八字仅存本地并加密；界面明示"仅保存在本机"
- 不上传任何房间模型/图片/八字数据
